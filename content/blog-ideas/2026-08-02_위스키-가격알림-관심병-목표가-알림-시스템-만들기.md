# 위스키 가격 알림 만들기 — 관심 병이 목표가 이하로 내려가면 알려주는 시스템

**기둥**: 💻 Code (개발·데이터)
**한 줄 요약**: 매일 수집되는 위스키 가격 데이터 위에 '목표가 도달 알림'을 얹는 방법을 단계별로 설명한다.

## 왜 이 글인가 (가치-대비-가격)

위스키 가격은 매장·셀러·시점에 따라 수시로 바뀐다. "글렌피딕 18년이 10만 원 아래로 내려가면 살 텐데" 같은 생각을 해본 사람은 많지만, 매일 직접 가격을 확인하는 건 현실적이지 않다. CaskCode는 이미 매일 5개 소스에서 50종 이상의 위스키 가격을 수집하고 있다. 이 인프라 위에 '알림 한 줄'을 얹으면, 서버 비용 없이도 개인용 가격 알림 시스템을 만들 수 있다.

- **독자 니즈 직결**: "언제 사야 하나"는 가장 자주 받는 질문. 알림은 그 답의 자동화다.
- **기존 자산 재활용**: 수집 파이프라인·정규화 DB가 이미 있으므로 추가 개발이 최소화된다.
- **Code 기둥 콘텐츠 부족 보완**: 55개 제안 중 Code는 5개뿐. 개발자 독자층 확대에 기여한다.
- **실용 튜토리얼**: 위스키가 아닌 다른 상품에도 적용 가능한 범용 패턴이라 공유 가치가 크다.

## 독자

- 위스키를 좋아하고 '최적 타이밍에 사고 싶은' 소비자 (비개발자도 개념 이해 가능)
- 데이터 수집·자동화에 관심 있는 개발자·데이터 분석가
- CaskCode의 데이터 인프라가 어떻게 작동하는지 궁금한 독자

## 구성 목차

1. **문제 정의** — 위스키 가격은 왜 직접 모니터링하기 어려운가
   - 소스가 5개 이상(마트·데일리샷·면세점·해외), 가격 변동 주기가 제각각
   - 수동 확인의 한계: 주 1회 확인으로는 할인을 놓친다
2. **데이터 흐름 개요** — CaskCode의 가격 수집 파이프라인 간략 소개
   - 매일 수집 → 정규화 → 소스별 최신가 → floor(국내 최저가) 산출
   - 이 흐름 위에 '알림 레이어'를 얹는 구조
3. **목표가 설정** — 관심 병과 '이 가격이면 산다'를 정의하는 방법
   - watchlist.csv 또는 JSON: `(canonical_id, target_price, channel)`
   - 목표가 설정 팁: 과거 최저가·현재가·평균가 데이터 활용
4. **알림 로직** — 매일 수집 후 목표가 비교, 조건 충족 시 알림 발송
   - 의사코드: `if latest_floor <= target_price: notify()`
   - 중복 알림 방지: 이미 알린 건은 재알림하지 않는 상태 관리
5. **알림 채널** — 이메일·슬랙·텔레그램, 서버 없이 보내는 방법
   - GitHub Actions + Gmail SMTP (CaskCode가 실제 쓰는 방식)
   - 대안: Slack webhook, Telegram Bot API
6. **실제 예시** — "글렌피딕 18년 ≤ 99,000원" 알림이 울린 날
   - 실제 수집 데이터에서 목표가 도달 사례 시연
7. **한계와 주의점**
   - 수집 데이터 = '수집일 기준가'이지 실시간 재고가 아님 (CLAUDE.md 데이터 관리 원칙)
   - 가격이 내려갔다고 재고가 있는 건 아님 — 매장 확인은 별도
   - 면세 가격은 국내 최저가와 별개 (CMPA-321 원칙)

## 우리가 가진 근거/소스

- **정규화 DB + floor 산출 로직**: `scripts/normalize_dataset.py`, `pipelines/common/source_floor.py` — 소스별 최신가 기반 국내 최저가 산출이 이미 동작 중
- **가격 변동 감지**: `pipelines/shilla_dutyfree/detect_price_changes.py` — 가격 변동 감지+이메일 알림 패턴이 이미 구현돼 있음 (이걸 일반화하면 된다)
- **이메일 발송 인프라**: `scripts/send_blog_idea.py`, Gmail SMTP — 서버 없이 이메일 알림 발송 가능
- **4개월치 가격 이력**: 50종 이상, 5개 소스, 일간 수집 — 목표가 설정의 근거 데이터
- **위스키 정본 목록**: `assets/whisky-list.csv` — canonical_id 기반 추적 가능
